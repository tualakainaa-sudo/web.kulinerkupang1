# Kuliner Kupang — Proyek Mini OBE

## Cara menjalankan
1. Ekstrak folder `kuliner-kupang`.
2. Buka folder tersebut di Visual Studio Code atau Visual Studio.
3. Buka `index.html` di browser. Jika memakai VS Code, ekstensi Live Server bisa digunakan, tetapi tidak wajib.
4. Pastikan koneksi internet tersedia untuk memuat gambar ilustrasi dan Google Fonts.

## File
- `index.html`: struktur halaman.
- `style.css`: desain dan tata letak responsif.
- `script.js`: pencarian, modal detail, text-to-speech, menu mobile, dan breadcrumb.
- `audio/`: tempat menyimpan audio rekaman sendiri bila ingin ditambahkan.

## Catatan
- Foto saat ini merupakan gambar ilustrasi eksternal. Ganti dengan foto asli yang memiliki izin penggunaan.
- Peta membuka pencarian Google Maps, bukan peta yang tertanam.
- Text-to-speech menggunakan fitur browser dan bukan rekaman bahasa daerah.
- Informasi alamat, harga, jam buka, serta data UMKM perlu diverifikasi.
- Website ini belum terintegrasi dengan OCR atau layanan NMT. Keduanya bisa ditambahkan sebagai pengembangan lanjutan.
- Deklarasi UTF-8 dan fitur aksesibilitas sudah disertakan, tetapi kepatuhan WCAG AAA perlu diuji dengan alat dan pemeriksaan manual.
